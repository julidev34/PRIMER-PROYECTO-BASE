# Football League Manager

Sistema de gestión de liga de fútbol en Java con menú interactivo.

## Características
- Crear equipos y jugadores
- Registrar partidos con goles
- Estadísticas por jugador
- Tabla de posiciones
- Ranking de goleadores

## Cómo ejecutar

```bash
javac src/*.java
java src.Main
```

## Tecnologías
- Java 11+
- Colecciones (ArrayList)
- Programación Orientada a Objetos
